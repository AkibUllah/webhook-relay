webhook-relay

Reliable webhook delivery: publish an event once and it is fanned out to every subscribed endpoint with HMAC signatures, exponential backoff, per-endpoint circuit breakers, dead-letter handling and one-click replay.

Source on GitHub Open in Codespaces Deploy to Render

This page is a static API reference built from the service's exported OpenAPI document on every push to main; there is no backend behind it, so requests cannot be sent from here. Open the Codespace to run the real service with demo data, or deploy your own copy to Render. In the Codespace the admin key is change-me (X-API-Key) and a live dashboard is served at /dashboard.
